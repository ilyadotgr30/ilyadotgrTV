# AGENTS.md — разработка, адаптация и установка ilyadotgrTV

## Назначение

Этот файл предназначен для программного агента, который имеет доступ к терминалу пользователя и репозиторию ilyadotgrTV. Агент может проверить совместимость, адаптировать исходники под другой Android-телевизор, собрать APK и — только после подтверждения — установить его.

Лаунчер изначально разрабатывался и проверялся только на телевизоре **Tuvio TQ55UFGSV1**, Android 11, плата CV9632H-A50, MediaTek/YaOS. На другом телевизоре установка может не пройти, назначение домашним экраном может быть заблокировано, а HDMI, источники, громкость и системные функции могут потребовать адаптации.

## Обязательные правила безопасности

1. Сначала выполняй только read-only проверки.
2. Не удаляй, не отключай и не очищай данные системных приложений.
3. Не меняй HOME-приложение без отдельного явного подтверждения пользователя.
4. Не выполняй factory reset, сброс сети или очистку пользовательских данных.
5. Перед любой установкой сообщи пользователю, что совместимость не гарантирована и установка выполняется на его страх и риск.
6. Если телевизор показывает RSA-запрос, код сопряжения или системное подтверждение, передай управление пользователю.
7. Не предполагай порт 5555, если телевизор показывает другой порт беспроводной отладки.
8. Устанавливай обновление с `adb install -r`, чтобы сохранить настройки.
9. Перед изменением кода создай отдельную ветку или явно покажи пользователю список изменяемых файлов.
10. Не добавляй в репозиторий IP-адреса пользователя, ADB-ключи, keystore, `local.properties`, логи или данные телевизора.

## Структура и точки адаптации

- `app/src/main/java/ru/ilyadotgr/tvhome/MainActivity.kt` — главный экран, список приложений, Dock, погода и обращения к системным функциям.
- `app/src/main/java/ru/ilyadotgr/tvhome/SettingsActivity.kt` — отдельный экран настроек.
- `app/src/main/AndroidManifest.xml` — HOME / Leanback intent-фильтры, разрешения и package queries.
- `app/src/main/res/` — иконки, обои, строки и оформление.
- `app/build.gradle` — minSdk 23, targetSdk 30, версия приложения и зависимости.

Для другого телевизора сначала найди в коде обращения к `com.yandex.tv.live`, `com.mediatek.tvinput`, TV Input, HDMI, аудио и системным Intent. Не заменяй их вслепую: сопоставь с пакетами и возможностями конкретного устройства.

## Этап 0. Адаптация исходников под другой телевизор

1. Выполни read-only сбор сведений из этапа 1.
2. Проверь текущую сборку командой `./gradlew assembleDebug`.
3. Составь таблицу различий между Tuvio/YaOS и целевым телевизором.
4. Предложи минимальный набор изменений и дождись подтверждения.
5. Реализуй изменения без удаления универсального fallback-поведения.
6. Собери APK и выполни локальные проверки до установки.
7. Установи тестовую сборку только после подтверждения пользователя.
8. Проверь пульт, HOME, Back, запуск приложений, погоду и возврат штатного лаунчера.

Если системный API производителя недоступен обычному приложению, не обходи защиту и не запрашивай root. Отключи или скрой неподдерживаемую функцию и опиши ограничение.

## Этап 1. Проверка совместимости

Собери:

```text
Точная модель телевизора
Версия Android и API
Наличие FEATURE_LEANBACK
Текущий HOME-пакет
Доступность установки APK
Список TV Input
Наличие com.yandex.tv.live
Наличие com.mediatek.tvinput
Архитектура устройства
Свободная память
```

Пример команд после подключения:

```bash
adb shell getprop ro.product.manufacturer
adb shell getprop ro.product.model
adb shell getprop ro.build.version.release
adb shell getprop ro.build.version.sdk
adb shell getprop ro.product.cpu.abi
adb shell pm list features
adb shell cmd package resolve-activity --brief -a android.intent.action.MAIN -c android.intent.category.HOME
adb shell pm list packages | grep -E 'yandex.tv.live|mediatek.tvinput'
adb shell dumpsys tv_input
adb shell df -h /data
```

Классифицируй результат:

- **Полная вероятная совместимость:** YaOS, Android 6+, MediaTek TV Input, присутствует `com.yandex.tv.live`.
- **Базовая совместимость:** Android TV / Google TV 6+, APK устанавливается, но HDMI и назначение HOME требуют проверки.
- **Несовместимо:** Tizen, webOS, VIDAA, Roku, Titan OS или Android ниже API 23.

Перед продолжением покажи пользователю таблицу: что будет работать, что может не работать, что требует адаптации.

## Этап 2. Помощь с режимом разработчика

Если режим разработчика или отладка не включаются, сначала определи точную модель и найди инструкцию производителя или надёжное описание именно для этой прошивки. Не предлагай скрытые сервисные меню без проверки и явного предупреждения.

Типовой путь:

```text
Настройки -> Система / Настройки устройства -> Об устройстве -> Сборка
Нажать OK 7 раз -> Для разработчиков -> USB debugging / ADB debugging
```

Для Android 11+ беспроводная отладка может показывать два разных порта: порт сопряжения и порт подключения. При необходимости выполни сначала `adb pair IP:PAIR_PORT`, затем `adb connect IP:CONNECT_PORT`.

## Этап 3. Подключение

1. Проверь IP через `ping`.
2. Посмотри `adb devices -l` и `adb mdns services`.
3. Если известен порт, проверь его доступность.
4. Выполни `adb connect IP:PORT`.
5. Если TCP-порт открыт, но ADB возвращает устаревшую сетевую ошибку, допустимо выполнить `adb kill-server`, `adb start-server` и повторить подключение.
6. Проверь, что подключён именно телевизор пользователя.

## Этап 4. Установка

Найди актуальный APK в `release/` или собери debug APK командой `./gradlew assembleDebug`. Затем:

```bash
adb -s IP:PORT install -r /absolute/path/to/app.apk
adb -s IP:PORT shell am force-stop ru.ilyadotgr.tvhome
adb -s IP:PORT shell am start -n ru.ilyadotgr.tvhome/.MainActivity
adb -s IP:PORT shell dumpsys package ru.ilyadotgr.tvhome
```

Проверь `versionCode`, `versionName`, запущенную Activity и отсутствие нового `FATAL EXCEPTION` в logcat.

## Этап 5. Назначение HOME

Это отдельная операция, требующая подтверждения пользователя.

1. Сначала проверь доступные HOME-activity и штатный лаунчер.
2. Предпочитай системный экран выбора HOME.
3. Не отключай штатный лаунчер.
4. После выбора проверь Home, Back, настройки и возврат штатной оболочки.
5. Если новый HOME не запускается, немедленно верни штатный вариант.

## Этап 6. Финальный отчёт

Сообщи:

- модель и API телевизора;
- установленную версию ilyadotgrTV;
- какие функции проверены;
- какие функции ограничены;
- назначен ли HOME;
- как вернуть штатный лаунчер;
- осталась ли отладка включённой.

Рекомендуй выключить сетевую отладку после завершения, если она больше не нужна.

## Основной промт для пользователя

```text
Изучи README.md и AGENTS.md в корне проекта и строго следуй им. Сначала только проверь совместимость моего телевизора и объясни, какие функции потребуют адаптации. Ничего не устанавливай и не меняй на телевизоре до моего подтверждения. Если адаптация нужна, внеси минимальные изменения в отдельной ветке, собери APK и покажи результат проверок. После моего подтверждения установи APK с сохранением данных, запусти приложение и проверь ошибки. Не отключай и не удаляй штатный лаунчер.
```
