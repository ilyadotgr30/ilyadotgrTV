# ilyadotgrTV

Минималистичный Android TV / YaOS-лаунчер с управлением с пульта, Dock, погодой, обоями, настройками оформления и интерфейсом для телевизора.

> [!WARNING]
> Проект разрабатывался и проверялся на **Tuvio TQ55UFGSV1**, Android 11, YaOS, плата CV9632H-A50. На другом телевизоре базовый интерфейс может работать, но HDMI-входы, системные источники, громкость и назначение HOME могут потребовать адаптации. Устанавливайте приложение на свой страх и риск и не удаляйте штатный лаунчер.

## Совместимость

| Платформа | Ожидаемый результат |
|---|---|
| Tuvio TQ55UFGSV1 / YaOS / Android 11 | Проверенная конфигурация |
| Другие Tuvio и YaOS | Требуется проверка системных пакетов и TV Input |
| Android TV / Google TV, Android 6+ | Базовый лаунчер обычно устанавливается; системные функции могут отличаться |
| Android-приставки | Интерфейс работает, но HDMI-входов телевизора обычно нет |
| Samsung Tizen, LG webOS, VIDAA, Roku, Titan OS | Android APK не поддерживается |

Минимальная версия — Android 6.0 / API 23. Для сборки используется target API 30, чтобы сохранить совместимость с Android 11.

## Быстрая установка

1. Включите режим разработчика и ADB на телевизоре.
2. Подключите компьютер и телевизор к одной сети.
3. Используйте IP и порт, показанные телевизором:

```bash
adb connect TV_IP:TV_PORT
adb -s TV_IP:TV_PORT install -r release/ilyadotgrTV-v0.30.0.apk
adb -s TV_IP:TV_PORT shell am start -n ru.ilyadotgr.tvhome/.MainActivity
```

Не считайте порт `5555` обязательным: Android 11 и некоторые прошивки используют другой порт. Назначайте приложение домашним экраном только после проверки и не отключайте штатный HOME.

## Установка и адаптация с помощью агента

Откройте репозиторий в агенте, имеющем доступ к терминалу, и используйте один промт:

```text
Изучи README.md и AGENTS.md в корне проекта. Сначала только проверь совместимость моего телевизора и объясни, какие функции потребуют адаптации. Ничего не устанавливай и не меняй на телевизоре до моего подтверждения. Если адаптация нужна, внеси минимальные изменения в отдельной ветке, собери APK и покажи результат проверок. После моего подтверждения установи APK с сохранением данных, запусти приложение и проверь ошибки. Не отключай и не удаляй штатный лаунчер.
```

`AGENTS.md` содержит безопасный порядок проверки, карту мест для адаптации и правила установки.

## Сборка из исходников

Требования: JDK 17, Android SDK 35 и интернет для первой загрузки Gradle и зависимостей.

```bash
./gradlew assembleDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

Релизная сборка в текущем проекте подписывается debug-ключом и предназначена для тестирования и прямой установки:

```bash
./gradlew assembleRelease
```

Для публикации в магазине создайте собственный release keystore и не добавляйте его в Git.

## Что обычно приходится менять для другого телевизора

- пакет или Intent системного приложения источников;
- получение списка HDMI / TV Input;
- команды управления громкостью и системными настройками;
- пакет штатного лаунчера и способ выбора HOME;
- названия специфичных для YaOS пакетов;
- размеры интерфейса при нестандартном разрешении или overscan.

Сначала соберите сведения через ADB, затем меняйте только зависимые от производителя участки. Подробный порядок находится в `AGENTS.md`.

## Данные и сеть

Погода загружается из Open-Meteo. Приложение запрашивает доступ к интернету и состоянию Wi-Fi, но не требует геолокацию устройства. Выбранный город и настройки интерфейса хранятся локально.
