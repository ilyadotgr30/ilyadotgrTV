# Visual references

TV Home draws its interface at runtime and does not bundle Apple or third-party visual assets.

- Apple Liquid Glass documentation and macOS 27 design resources were used as design references.
- `shivvyas2/macbook-launchpad` (MIT) informed the full-screen grid and pagination model.
- `vinceliuice/WhiteSur-icon-theme` (GPL-3.0) was reviewed as a geometry reference only; no icons or source files were copied.
- `emilkowalski/skills/skills/apple-design` informed response, motion, material, typography, and restraint decisions.
- Weather data is provided by Open-Meteo for fixed Moscow coordinates; no location permission is requested.
- Bundled wallpaper photos: Benjamin Voros (`phIFdC6lA4E`), Haseeb Jamil (`3s85IxVDyXE`), and BoliviaInteligente (`yIbz_ts9-tQ`) on Unsplash.
